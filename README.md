# Web Snake Classic 
Eat, grow, avoid walls and your own tail — a classic Snake arcade game. 

[Live Demo](https://snstanislav.github.io/ordinary-web-calculator/) 

## Features
- Scalable playing field based on window size
- Adjustable speed levels
- Keyboard controls
- Retro pixel-art style

## Tech Stack
- TypeScript
- React.js 19.1.0
- SASS

## Getting Started 

```bash
git clone https://github.com/snstanislav/web-snake-classic.git
cd web-snake-classic
npm install
npm start
```
The app will open at http://localhost:3000
